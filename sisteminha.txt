Entender o problema:
	Falta de controle e visualização de finanças pessoais, saldo e categorias de gastos. 
Levantar os requisitos funcionais e não funcionais: 
	Requisitos Funcionais: 
		1-Cadastrar Receitas
		2-Cadastrar despesas
		3-Somar ganhos e gastos
		4-Calcular o saldo automaticamente
		5-Gerar relatórios mensais
		6-Mostrar as maiores categorias de gastos
		7-Avisar contas perto de vencer
		8-Editar e excluir receitas e despesas
	Requisitos não funcionais: 
		1-Usabilidade fácil
		2-Segurança
		3-Desempenho
		4-Atualizar saldo rapidamente
		5-Proteger os dados financeiros
		6-Disponibilidade
		7-Permitir acesso quando necessário
		8-Confiabilidade
		9-Calcular valores corretamente

Para fazermos uma conexão com nosso banco de dados criamos uma pasta chamada src e dentro dela um arquivo chamado
bancoDados.ts

começamos importando o dotenv para segurança dos dados e também o Pool para uma melhor conexão entre os bancos de dados.
import {Pool} from 'pg';
import dotenv from 'dotenv';

depois ativamos as configurações:
dotenv.congif();

e fazemos uma caminha Pool para receber as informações do banco de dados e gerar conexão
const conexaoBanco = new Pool(){
    host: process.env.BD_HOSPEDEIRO,
    port: Number(process.env.BD_PORTA),
    user: process.env.BD_USUARIO,
    password: process.env.BD_SENHA,
    database: process.env.BD_NOME,
} 
a variável const vai garantir que os arquivos são sejam alterados.

FEITO ISSO PASSAMOS PARA A ESTRUTURAÇÃO DA API 
para isso precisamos criar um novo ficheiro chamado servidor.ts, que vai receber as requisições do navegador, frontend ..
e ligar essa rota ao banco de dados.

começamos importando o express que é o framework que vamos utilizar 
import express from 'express';
e também o dotenv para proteção dos dados do banco de dados
import dotenv from 'dotenv'; 

ativamos a configuração do dotenv
dotenv.config();

e criamos duas váriaveis que vão receber uma o framkework e outra a porta de entrada do banco de dados
const app = express();
const porta = process.env.PORTA || 3000;

em seguida vamos fazer uso da aplicação app
app.use(express.json();
app.get('/',(requerimento, resposta) => {
	resposta.send('API do sistema de finanças está rodando')
});
app.listen(porta, () => {
    console.log(`Servidor rodando na porta ${porta}`);
})
